制作期間
2025年10月から2026年2月まで　約5ヶ月

ゲーム内容
制作した作品の内容はC++とDXライブラリを使用して個人制作した3Dアクションゲームです。プレイヤーはNPCと協力しながら敵を倒してステージを進み、最奥のボスを撃破することが目的です。プレイヤーとNPCはそれぞれ戦士と魔法使いの2種類のキャラクターで構成されており、敵によって有利なキャラクターが異なるため、状況に応じてプレイヤーキャラクターをNPCと切り替えながら攻略することが重要な要素となっています。プレイヤーはキャラクターごとの役割や敵との相性を考えながら進む必要があり、協力と切り替えを活かした戦略的なゲームプレイを楽しめる作品です。


アピールポイント
この作品ではNPCが追従して協力して戦ってくれるだけではなく、プレイヤーとNPCを切り替えて戦うことができることが特徴です。プレイヤーとNPCは戦士キャラと魔法使いキャラの2種類のキャラがおり、敵によって有利なキャラクターが異なるため状況に応じてプレイヤーとNPCを切り替えながら攻略することが重要な要素となっています。キャラクターのAIでは戦士キャラが敵にひたすら攻撃するだけになって攻撃を避けない状態にならないように敵の攻撃を感知して自動で回避を行うようにして、魔法使いキャラは安全に攻撃するために敵が近づくと距離をとってから攻撃をするようにしました。敵が同じ敵ばかり狙わないようにヘイト値を設定し、敵からの距離が近いか攻撃を受けるとヘイト値が増加するようにしています。
技術的に苦労したところは地形との当たり判定やキャラクター同士の押し戻しです。地形との当たり判定では着地時の床との当たり判定がすり抜け、特定の場合に壁にめり込んでしまうことが発生し、キャラクター同士の押し戻しでは意図しない距離で先に進めなくなるほどの強烈な押し戻しが発生しました。また、当初表示用のモデルで当たり判定を行うと移動時にガタついたり壁の装飾での引っ掛かりが発生しました。解決のために友人に相談やサイトを調べて試行錯誤を繰り返しました。地形に対してはレイキャストを用いた接地判定と、複数の壁に挟まれた際の挙動を安定させるための反復計算を導入しました。キャラクター間の押し戻しでは、単なる距離判定ではなくめり込み量に基づいた座標補正を行いました。移動時のガタつきや引っかかりは表示用のモデルとは別に当たり判定用の凹凸の少ないモデルを用意し、そちらで当たり判定を行うことで解決できました。
